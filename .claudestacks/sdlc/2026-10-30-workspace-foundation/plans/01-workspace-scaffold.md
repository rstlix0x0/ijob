# Workspace Scaffold Implementation Plan

**Goal:** A four-member uv workspace on Python 3.14 passes the python guideline gate from the repository root.

**Content authority:** `intent.md` of this chain (spec skipped).

**Architecture:** A virtual root (no `[project]` table) holds the strict-quality baseline, the pinned
`dev` group and `[tool.uv.workspace] members = ["packages/*"]`. Four library members —
`ijob-core`, `ijob-sources`, `ijob-ai`, `ijob-app` — each import as `ijob_core`, `ijob_sources`,
`ijob_ai`, `ijob_app`, ship `py.typed`, and keep tests in `packages/<member>/tests/<import>_tests/`.
No member depends on another yet and no member carries feature code.

**Tech Stack:** uv 0.13.6, CPython 3.14, ruff 0.17.3, mypy 2.4.1, pytest 9.2.0, `uv_build` backend.

`claudestacks-guideline-python` plugin, `skills/python-guidelines/`):

### Task 1 — Root configuration

**Files:**
- Create `pyproject.toml`
- Create `.python-version`
- Create `.gitignore`

**Change:** the root `pyproject.toml` is a virtual root: no `[project]`, no `[build-system]`. It
carries, verbatim from `strict-quality.md`, the `[dependency-groups] dev` pins
(`mypy==2.4.1`, `pytest==9.2.0`, `ruff==0.17.3`), the `[tool.ruff.lint]` `extend-select` list,
`[tool.ruff.lint.pydocstyle] convention = "google"`, `[tool.mypy]` (`strict`, `warn_unreachable`,
`enable_error_code = ["explicit-override"]`) and `[tool.pytest]` (`minversion`, `strict`,
`filterwarnings = ["error"]`, `addopts` with importlib mode and doctest-modules), with the
workspace adaptations from `workspace.md`: `testpaths = ["packages"]`, per-file ignores keyed
`"packages/*/tests/**"` = `["S101", "PLR2004", "D"]`, and `[tool.uv.workspace] members = ["packages/*"]`.
`.python-version` holds `3.14`. `.gitignore` lists: `.venv/`, `__pycache__/`, `*.py[oc]`,
`build/`, `dist/`, `wheels/`, `*.egg-info`, `.mypy_cache/`, `.ruff_cache/`, `.pytest_cache/`,
`.env`, `*.db`, `/data/` (anchored to the root), `.deepeval/`, `.DS_Store`. It must not ignore
`uv.lock`, `.python-version` or `.env.example`.

**Proof:** no Python behaviour; these commands all succeed —
- `uv run --no-project --python 3.14 python -c "import tomllib; d = tomllib.load(open('pyproject.toml','rb')); assert 'project' not in d; assert d['tool']['uv']['workspace']['members'] == ['packages/*']; assert d['tool']['pytest']['testpaths'] == ['packages']"`
