# Milestone: Agents

## Goal

A source-discovery agent turns a company name or careers URL into a verified source (detects the
hiring system, probes it, checks identity, registers it). A custom-instruction ReAct agent explores
and proposes sources and companies. Both are evaluated with DeepEval agent metrics and traced.

## Non-goals

- Headless browsing.
