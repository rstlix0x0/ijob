# Milestone: TUI

## Goal

A Textual TUI covers search with filters, results, source management, CV upload (stored for
later use), and 👍/👎 labeling of results, on top of the same pipeline the CLI uses.

## Non-goals

- LLM features (match reasons, judging, scoring arrive with the LLM layer).
- New pipeline capabilities.
