# Milestone: Foundation

## Goal

A uv workspace (`ijob-core`, `ijob-sources`, `ijob-ai`, `ijob-app`, flat `ijob_*` imports) on
Python 3.14 passes the python guideline gate locally and in CI. An Apache-2.0 LICENSE, a portfolio-first
