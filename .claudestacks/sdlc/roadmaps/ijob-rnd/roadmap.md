# Roadmap: ijob R&D

## Vision

ijob is an R&D project and portfolio piece on building an agentic job search with LLMs. The work
ahead is LLM integration: rank postings against a CV, measure the LLM steps, optimize cheap models,
record the results and add agents. Each milestone ends with a result shown on real data.

## Non-goals

- Promoting ijob to users or supporting it as a product.
- More job sources or TUI work, unless a milestone needs it.
- Bypassing anti-bot protection, logged-in scraping or applying to jobs automatically.
