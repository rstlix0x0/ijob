# Milestone: Evals and agents

## Goal

Models from several vendors label about 100 postings, and the user decides only where they disagree. DeepEval suites measure the judge and the scorer against those labels and report the scores of a run. An agent turns a company name or careers URL into a verified source, and an agent follows custom instructions to explore sources and companies. Both are traced and evaluated.

## Non-goals

- Running LLM evaluations in CI.
- Agents that apply to jobs or contact anyone.
