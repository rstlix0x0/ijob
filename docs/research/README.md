# Source research

Research into where software-engineering job postings can be collected politely. Gathered on
2026-10-30. Endpoints, response shapes and robots.txt rules change over time, so re-check a finding
before relying on it.

| File | Contents |
|---|---|
| [`global_boards.md`](global_boards.md) | Global, remote and niche job boards: access method, robots.txt verdict, feasibility |
| [`asia_and_requested.md`](asia_and_requested.md) | Asia and Japan boards, plus the sources requested first |
| [`ats_endpoints.md`](ats_endpoints.md) | Public endpoints of hiring systems (ATS) behind company career pages |
| [`companies.csv`](companies.csv) | Company seed list with the hiring system and board slug each one uses |
