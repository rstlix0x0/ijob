# Global / remote / niche job sources for ijob (SWE focus)

Checked live on 2026-10-30 with curl. Usually one request per endpoint, spread across hosts (never more than 1 req/s to the same host). Generic UA: `Mozilla/5.0 (compatible; ijob-research/0.1)`.
robots.txt was evaluated with Google longest-match semantics for `User-agent: *`. Python's stdlib `urllib.robotparser` uses first-match and gives wrong ALLOW answers on files like landing.jobs and nofluffjobs. ijob should not rely on it as-is.

Notes:
- "SWE count" is what one request returned on 2026-10-30, not the full inventory unless marked "total".
- Several sites block AI-training crawlers by name (ClaudeBot, GPTBot, anthropic-ai) but allow `*`: RemoteOK, EuroTechJobs, Get on Board, Built In. ijob should send its own honest UA, not one of those names.
- Attribution / link-back is a common ToS condition (RemoteOK, Remotive, Arbeitnow, Jobicy, 4dayweek). A personal CLI that shows the original URL meets it.

## Rejected / blocked / dead

- **Stack Overflow Jobs**: dead (shut down in 2022). `/jobs` now returns 403.
- **Honeypot**: www.honeypot.io no longer serves (connection fails). Platform shut down.
- **Swiss Dev Jobs / German Tech Jobs / DevITjobs family**: `/api/jobsLight` and the homepages all 302 to `devitjobs.jobcopilot.com/signup`. Merged into JobCopilot (login-gated).
- **Wellfound (AngelList)**: one page returned 200 with `__NEXT_DATA__`, but the ToS forbids scraping and the site runs aggressive anti-bot protection. Not suitable.
- **Work at a Startup (YC)**: curl gets 406, and full listings need a login. Use ycombinator.com/jobs instead (verified above).
- **Dice**: robots disallows `/jobs?q*`, `/job*` (covers job-detail) and `/rss/`. No sanctioned feed.
- **Remote.co**: TLS connects, then the request stalls with no response (bot manager). Blocked for non-browsers.
- **rustjobs.dev, scalajobs.com, golang.cafe, echojobs.io**: 429 "Vercel Security Checkpoint" JS challenge. Would need anti-bot bypass.
- **startup.jobs, hiring.cafe, climatebase.org, rubyonremote.com, euremotejobs.com (feed), jooble.org**: Cloudflare 403 / "Just a moment" challenge.
- **Jooble API**: keyed POST API exists, but the docs page is behind a Cloudflare 403. UNVERIFIED.
- **JustRemote**: client-side rendered SPA, no jobs in the HTML, no feed found.
- **aijobs.net / ai-jobs.net**: both redirect to foorilla.com (pivoted to an "intelligence workspace"). It has an `/api/` page, but no job JSON confirmed. UNVERIFIED.
- **aijobs.ai**: robots `Disallow: /job/` (detail pages). The listing page alone is too thin.
- **functional.works / WorksHub**: redirects to works-hub.com and returns 404. Defunct.
- **Haskellers.com jobs**: parked domain.
- **This Week in Rust jobs**: the RSS is the newsletter only. Jobs moved to a quarterly r/rust "who's hiring" Reddit thread (Reddit API needs OAuth).
- **filtra.io (Rust)**: JS-only SPA, empty HTML. UNVERIFIED.
- **pythonjobs.github.io**: Atom feed stale (last entry 2022-10).
- **Dynamite Jobs RSS**: feed stale (pubDates 2025-03) and non-SWE-focused.
- **remotepython.com**: jobs feed has 1 item.
- **Jobspresso**: `/feed/` has 0 items.
- **VueJobs**: the feed at app.vuejobs.com/feed/posts is robots-disallowed.
- **Remote Rocketship, NoDesk, Relocate.me**: HTML loads, but no job data was found in the server-rendered HTML (client-rendered or a different structure). UNVERIFIED, low priority.
- **Torre.ai**: search API `search.torre.co/opportunities/_search` exists, but the POST body format was rejected ("Invalid request"). UNVERIFIED.
- **Kotlin/Android/DevOps niche boards tried (kotlinjobs.dev, androidjobs.io, devopsjobs.io, remotefront.dev)**: DNS failure or 404. No viable Kotlin/DevOps-only board found.
- **Excluded by scope**: LinkedIn, Indeed, Glassdoor, ZipRecruiter, Asia/Japan boards, company ATS boards.
